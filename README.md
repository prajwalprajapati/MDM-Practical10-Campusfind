# 🔎 CampusFind – Campus Lost & Found Portal

> A simple and responsive frontend prototype designed to help students report, search, and manage lost and found items within a campus.

---

## 📌 About the Project

CampusFind is a basic frontend web application created as part of a practical implementation using **HTML, Tailwind CSS, and JavaScript**.

The idea is based on a common campus problem — students often lose personal belongings such as earphones, books, ID cards, accessories, and other items, while found items may not easily reach their owners.

This project provides a simple digital platform where students can:

- Report a lost item
- Report a found item
- Search for reported items
- Filter reports by type and category
- View contact information
- Mark an item as resolved
- Keep data stored in the browser using LocalStorage

> ⚠️ **Current Status:** This is currently a basic frontend practical/prototype implementation.  
> The project is planned to be developed further into a fully functional real-world application.

---

## 🎯 Project Objectives

- Build a practical real-world frontend application
- Use **semantic HTML** for proper page structure
- Use **Tailwind CSS** for responsive and modern UI design
- Use **JavaScript DOM manipulation** for client-side interactivity
- Implement responsive layouts using Tailwind breakpoints
- Demonstrate basic browser-side data storage using LocalStorage

## 📱 Responsive Design

The application is designed to work across different screen sizes using Tailwind CSS responsive breakpoints such as:

- `sm:` – Small screens
- `md:` – Medium screens
- `lg:` – Large screens

The layout automatically adapts for mobile, tablet, and desktop devices.
